## Objectives & Focus Areas

The primary goal of these major projects is to foster research, innovation, and real-world problem-solving skills among students. Key targets include:

* **Research Publication:** Preparing high-quality manuscripts targeting IEEE, Springer, or Scopus-indexed conferences/journals.
* **Intellectual Property:** Encouraging patentable solutions and novel product architectures.
* **Production-Ready Implementations:** Building robust, well-documented, end-to-end software applications.

## Evaluation Criteria

Project performance will be evaluated based on the following breakdown:

* **Innovation & Problem Scope:** 30%
* **Technical Implementation & Code Quality:** 25%
* **Experimental Results & Validation:** 20%
* **Documentation & Research Paper Draft:** 15%
* **Presentation & Viva Voce:** 10%

## Submission Guidelines

1. **Version Control:** Maintain clean, modular code structured logically inside designated project directories.
2. **Commit History:** Avoid monolithic commits. Push meaningful, documented commit messages reflecting incremental progress.
3. **Documentation:** Each project folder must contain a comprehensive `README.md` describing setup instructions, dataset details, architecture diagrams, and reproduction steps.
