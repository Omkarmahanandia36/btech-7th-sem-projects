## 📋 Submission Guidelines & Rules

### Mandatory Requirements

| Category | Requirement | Penalty for Non-Compliance |
|---|---|---|
| 🔒 **Code Originality** | Plagiarism is strictly prohibited. All code must be 100% original work. | Zero marks on affected modules / possible disciplinary action |
| 📤 **Repository Updates** | Regular weekly commits required with meaningful commit messages. Monolithic commits are heavily discouraged. | Marks deduction in Technical Implementation scoring |
| 📁 **Project Structure** | Each project must reside in a dedicated folder: `Group_Name_Project/` with consistent naming | Rejection of submission until corrected |
| 📚 **Documentation** | Each project folder must contain a comprehensive local `README.md` with setup instructions, usage guide, and results | 10% marks deduction if missing or incomplete |
| 🔗 **GitHub Repository** | Public/Private repository link with CI/CD pipelines (optional but recommended) | Easier evaluation and version tracking |

## 🚀 Getting Started

### Step 1: Clone the Repository
```bash
git clone https://github.com/yourusername/BTech-Major-Projects-2026.git
cd BTech-Major-Projects-2026
```

### Step 2: Create Your Project Folder
```bash
mkdir "Your_Team_Name_Project"
cd "Your_Team_Name_Project"
```

### Step 3: Initialize Git & Start Development
```bash
git init
git add .
git commit -m "Initial commit: Project setup"
```

### Step 4: Document Everything
- Create a detailed `README.md` in your project folder
- Include setup instructions, dependencies, and usage examples
- Add research methodology and results
